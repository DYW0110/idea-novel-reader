# Novel Reader - IntelliJ IDEA 沉浸式小说阅读插件 📖

> 一款嵌入在 IntelliJ IDEA 中的沉浸式本地小说阅读与摸鱼插件，支持自适应排版、智能分章、无限滚动与深度代码/日志伪装。

---

## ✨ 核心特性

- 🎯 **自适应响应式排版**：正文自动根据 IDE 侧边栏宽度自适应折行（Word Wrap），左右舒适留白，大屏居中限制最大宽度，拒绝长行疲劳。
- 🧭 **两行极简控制栏**：
  - **第一行**：居中展示当前章节名称与百分比进度（如 `第272章 宇智波与大蛇丸的交易 (54.9%)`）。
  - **第二行**：纯文本功能按钮（`打开书籍`、`章节目录`、`< 上一章`、`下一章 >`、`代码伪装`、`阅读设置`、`收起工具栏`），杜绝图标方块乱码。
- 📂 **全格式智能分章与编码识别**：
  - 支持 `UTF-8`（带/无 BOM）及 `GBK` 自动探测与无乱码解析；
  - 智能正则匹配各类型章节标题（`第X章/节/卷`、`Chapter X`、`数字序号` 等）。
  - 支持直接将 `.txt` 小说文件**拖拽**至插件窗口打开。
- 📑 **悬浮抽屉式目录**：
  - 侧边滑出抽屉式章节列表，内置**即时搜索过滤框**（支持按章节数或关键词实时过滤）。
  - 当前阅读章节高亮并自动滚动居中，点击章节后自动收起并平滑跳转。
- 🎨 **多主题与个性化排版**：
  - **预设主题**：[跟随 IDE]（自动提取当前 Editor 背景与前景色）、[羊皮纸]（护眼米黄）、[深色代码]、[纯黑极简]、[自定义取色]；
  - 支持滑块调节字号（12-36px）、行间距倍数（1.0x-3.0x）、段间距（0.5em-3.0em）、正文最大宽度以及首行缩进。
- 🕶 **深度代码/日志伪装模式（Boss Key）**：
  - **控制台日志模式**：正文毫秒级添加时间戳、线程名及 `INFO c.m.n.service.NovelWorker` 前缀，字体强制切换为 `JetBrains Mono`，远看宛如正在运行的控制台 Log；
  - **Javadoc 代码注释模式**：将正文整齐包裹为多行标准代码注释。
- 💾 **阅读进度自动记忆**：
  - 翻页或退出时自动保存阅读进度与字符偏移量，下次打开 IDE 自动无缝恢复。

## ⌨️ 快捷键列表

| 功能 | 快捷键 | 说明 |
| :--- | :--- | :--- |
| **代码伪装 / 恢复** | `Ctrl + Alt + B` | 一键在小说正文与控制台日志/代码注释间切换 |
| **切换章节目录** | `F7` 或 `Ctrl + Alt + L` | 展开/收起悬浮章节抽屉目录 |
| **切换顶部工具栏** | `F8` 或 `Ctrl + Alt + T` | 显示/隐藏顶部导航栏 |
| **打开小说文件** | `Ctrl + Alt + O` | 呼出本地小说文件选择器 |
| **上一章 / 下一章** | `Alt + ↑` / `Alt + ↓` | 快速跨章节切换 |
| **翻页滚动** | `PageUp` / `PageDown` / `Space` | 平滑向下/向上滚动一屏 |

## 📦 安装使用

### 方式一：从 Release 下载安装包（推荐）
1. 下载打包好的安装包：`idea-novel-plugin-1.0.0.zip`
2. 打开 IntelliJ IDEA，进入 **Settings** (`Ctrl + Alt + S`) -> **Plugins**。
3. 点击右上角 ⚙️（齿轮图标），选择 **Install Plugin from Disk...**。
4. 选择下载的 zip 文件安装并重启/启用插件即可。

### 方式二：本地源码编译
```bash
# 克隆仓库
git clone https://github.com/DYW0110/idea-novel-reader.git
cd idea-novel-reader

# 使用 Gradle 编译打包 (需要 JDK 17+)
./gradlew buildPlugin
```
生成的安装包位于：`build/distributions/idea-novel-plugin-1.0.0.zip`
